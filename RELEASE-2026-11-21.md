# vegas26 current — 2026-11-21

Tested on **moto g power - 2026** (`XT2617V` / `vegas26`), firmware
`W1WEOS36.48-22-3-3-4-3`, Android 16, bootloader unlocked, slot `_a`.

This release contains the exact GSI and recovery used on the device, plus the original
OrangeFox base image used to build the working recovery.

## Assets

| File | What it is |
|---|---|
| `LineageOS-23.2-2026.11.18-microG-gsi.img.xz` | Android 16 LineageOS 23.2 microG GSI (decompress before flashing) |
| `vegas_ofox_fixed.img` | **OrangeFox R12.0** recovery for `vendor_boot_a`, with the stock Focaltech FT8725 touch module |
| `vegas_ofox_base.img` | original XDA `vegas_ofox.img` base (not flashed; for reproducing the repack) |
| `SHA256SUMS-2026-11-21.txt` | hashes |

The decompressed GSI `.img` is **2.9 GB** and is not a release asset (GitHub’s 2 GB/file
limit). Decompress the `.xz`; the SHA-256 of the resulting image is in the checksums
file.

## What works

- Android 16 / LineageOS 23.2 microG GSI booting from `system_a`.
- `/data` encrypted; OrangeFox decrypts it.
- Recovery touch (`ft8725` / `fts_ts` / event2), backup/restore, MTP, ADB.
- Wi-Fi operation; no SIM required.

## What this does not do

- Does **not** SIM/network-unlock the modem. Bootloader unlock and SIM lock are
  independent; a carrier lock stays in `md1img`.
- Does not install Google apps; microG is built into this GSI. Use F-Droid/Aurora Store
  if you want apps.
- Does not replace the stock `vendor`/`modem`; the GSI only replaces `system`.

## 16.0 source experiments (not release assets)

The OrangeFox 16.0 source build compiles and verifies, but is **not** a working recovery:
the 16.0-built platform fails at the bootloader, and the 16.0 recovery on the R12.0
platform only reaches the OrangeFox splash, never the menu. Full details, image hashes and
the bootloader size limit are in `docs/05-ofox16.md`. No 16.0 image is published here as a
working recovery.

The working recovery is **OrangeFox R12.0**, not 14.1. The TWRP 14.1 source and the
OrangeFox 14.1/16.0 source builds are newer controls; the 12.1/R12.0 branch is the true
source control for the working image.

## SIM / modem (not in this release)

The modem unlock is separate from the bootloader unlock. The offline `vegas-freedom` build
for this `-4-3` unit passed its audit, but it has **not been flashed**. Only `md1img_a` is
flashed; never `md1img_b`/`lk`/`preloader`/`seccfg`/`gpt`/`nvram`/`nvdata`/`protect*`.
Verification needs a non-Tracfone SIM (US Mobile Dark Star/AT&T is the tested one; a
Verizon MVNO may reject the IMEI). See `docs/07-modem-unlock.md` and
`docs/06-sim-setup.md`.

## Flash the GSI

1. From the bootloader, disable verification:
   ```powershell
   fastboot --disable-verity --disable-verification flash vbmeta        vbmeta_a.img
   fastboot --disable-verity --disable-verification flash vbmeta_system vbmeta_system_a.img
   ```
2. Enter fastbootd and flash:
   ```powershell
   fastboot reboot fastboot
   fastboot flash system LineageOS-23.2-2026.11.18-microG-gsi.img
   ```
3. Use **stock recovery’s factory reset** for the first `/data` wipe. Do **not** use
   `fastboot -w`; it erases but does not format `/data`/`metadata`, and the second boot
   loops.
4. First boot takes 5–10 minutes.

## Flash the recovery

```powershell
fastboot flash vendor_boot_a vegas_ofox_fixed.img
```

Enter recovery from the bootloader menu: **Volume Down → `Recovery mode` → Power**.
`fastboot reboot recovery` boots normal Android on this unit.

## Revert to stock

Keep private raw backups. Restore `super.img` in fastbootd, reflash stock
`vbmeta`/`vbmeta_system`, and flash the stock `vendor_boot_a.img`. Then factory reset.

## Warnings

- Never relock the bootloader with modified `lk`/`init_boot`.
- Do not flash another device’s recovery/ROM.
- Keep `nvram`, `nvdata`, `seccfg`, `persist`, `frp`, `protect*`, `md1img` private.
- The recovery is OrangeFox (TWRP-based), not TWRP-branded.
